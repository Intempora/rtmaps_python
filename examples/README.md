# rtmaps_python Examples

## REST
Contains the REST API for the RTMaps Runtime engine. 
Start it with `python REST/rtmaps_typed_rest_api.py`

## WEB UI 
Contains a simple HTML/JSS web page that makes use of the RTMaps REST API. 
Start it with `python WebUI/rtmaps_web_control_ui.py`
By default the UI is accessible on : http://127.0.0.1:8080/webui/index.html
